# ⏰ Digital Clock & Countdown Timer

A responsive and interactive **Digital Clock & Countdown Timer** built using HTML, CSS, and JavaScript.

The project displays the current time in real time and includes a countdown timer to New Year 2027.

## 🚀 Live Demo

👉 **[View Live Project](https://digital-clock-countdown.vercel.app/)**

## 📂 GitHub Repository

👉 **[View Source Code](https://github.com/pratyusha8283/digital-clock-countdown)**

## ✨ Features

- 🕐 Live digital clock with HH:MM:SS format
- 📅 Real-time date display
- ⏳ Countdown timer to New Year 2027
- 🔄 Automatically updates every second
- 🎨 Modern glassmorphism-style interface
- ✨ Hover animations
- 📱 Responsive and mobile-friendly design
- ⚡ Lightweight and fast

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling, responsive design and animations
- **JavaScript** – Clock and countdown functionality
- **Date() Object** – Handling date and time
- **setInterval()** – Updating the clock and countdown every second
- **DOM Manipulation** – Dynamically updating webpage content
